Van Buren Bay: evidence for terrain-refined additions

Diagnostic mapping support for actively connected terrain additions: source distance, distance beyond current native flooding, and earlier/later native wet support. A matched 0.10 m results file is unavailable for this domain; the wetting-scenario comparison is omitted, rather than borrowed from another domain. Grey water is unscored. These classes are not probabilities.

Matched 0.10 m scenario unavailable: no cross-domain baseline is substituted. Scenario-comparison support is omitted. Other diagnostics use this site's source simulation.

MetricMeaning
Combined mapping evidenceCombines source and modelled-boundary distances with native wet support during the same 0.01 m wetting simulation. Closer means source distance ≤50 m and boundary distance ≤25 m. These are project review classes, not calibrated flood probabilities.
Distance from source cellDistance to the nearest eligible current source supporting the eight-source spatial blend, before the spatial Gaussian. This is not a distance to every contributor or a weighted-effective source. Native heads are unchanged.
Distance beyond model boundaryEuclidean pixel-centre distance to the closest currently finite native wet footprint in the displayed extent. It uses every finite native element, including components excluded from the offshore-connected donor pool. This is a 1 m raster distance, not channel length or the exact vector shoreline.
Flooded elsewhere in this eventFor each currently added pixel, checks the same original element for finite output before and after the current timestep in the Wet0.01 run. All 649 saved outputs are considered, including outputs before the viewer crop. Later wet support corroborates spatial reach within this simulation; it does not confirm that flooding occurred here at the current time, and is not an observation.

Distances are straight-line mapping diagnostics, not flow-path lengths. The source-distance layer uses the nearest eligible contributor before spatial smoothing. Earlier or later model flooding is simulated support for spatial reach, not an observation or proof of flooding at the selected time. Native support means finite saved water level, not a reconstruction of every active solver cell. Only active additions are scored; grey and cosmetic shoreline fringe remain unscored.

Primary source context

  • Bryant et al. (2024), resolution enhancement of flood inundation grids: The present nearest-centre/Gaussian mapper is not CostGrow. This paper does not calibrate the viewer diagnostic thresholds.

  • DHI MIKE 21 FM scientific documentation (2026), section 3.3.5: Finite eta is saved-output availability, not a reconstruction of all computationally active cells.
